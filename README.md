# Лендинг «Опора» — демо Valora для ниши «психология»

Одностраничник частной практики психолога. Третий деливерабл Valora после
презентации КП и трёх лид-магнитов: показывает, как выглядит «обёртка»
(лендинг + лид-магнит + чат-бот) в живом виде.

**Всё вымышлено:** имя, образование, отзывы, цены, контакты. В подвале
об этом сказано прямо — макет показывают заказчику, а не выдают за практику.

## Запуск

```bash
# просто открыть в браузере
start index.html

# скриншоты страницы целиком (PNG + нарезка на экраны)
PYTHONIOENCODING=utf-8 python shot.py          # десктоп 1440
PYTHONIOENCODING=utf-8 python shot.py 500      # узкий экран
```

Сайт статический: `index.html` + `styles.css` + `script.js` + `fonts/` + `img/`.
Заливается на GitHub Pages как есть, сборки нет.

## Структура страницы

Порядок взят с присланного образца `murzzsite.github.io/gorizont-msk`
и переложен на частную практику одного специалиста.

| Блок | Что делает |
|---|---|
| Шапка | Липкая, якоря по разделам, телефон, кнопка записи |
| Первый экран | Оффер + форма быстрой заявки справа + лента из пяти цифр |
| С чем приходят | Шесть запросов, описанных ситуацией, а не чувством |
| Гид «7 ошибок» | Тёмная полоса — лид-магнит в обмен на почту |
| Обо мне | Иллюстрация + таблица фактов + блок «с чем я не работаю» |
| Как проходит | Сцена встречи + пять шагов на общей линии |
| Форматы и цены | Четыре карточки, средняя выделена |
| Отзывы | Три анонимных, с оговоркой о согласии |
| Вопросы | Аккордеон на шесть пунктов |
| Заявка | Контакты + большая форма |
| Подвал | Навигация, связь, пометка о демо |

## Решения

- **Палитра — песочно-терракотовая (`sand` из лид-магнитов)**, не сине-белая,
  как в образце. Лендинг и гид «7 ошибок» показываются в одном видео-КП
  и должны читаться как одна воронка. Плюс отстройка: психология в синем
  корпоративе выглядит клиникой.
- **Шрифты Manrope 800 + Inter** — те же, что в лид-магнитах. У Jost нет
  рабочего жирного, а продающий контраст держится на весе.
- **Тексты — из гида.** Оффер, форматы работы, шаги и оговорка про сроки
  взяты из `leadmagnets/content.py` (словарь `PSY`) и сжаты.
  Тон тот же: «вы», без обещаний результата, ситуация вместо чувства.
- **На сайте — фотографии, не рисунки.** Решение пользователя: гид читают
  как гид, а сайт должен выглядеть работающим, и рисованный психолог
  на нём сразу выдаёт макет. Файлы и источники — `img/CREDITS.txt`.
  Подбирались тёплые кадры с натуральным светом: терракотовые сиденья
  и песочные стены попадают в палитру без фильтров, а фильтр на фото
  всегда виден.
  - `img/hero-band.jpg` — полоса во всю ширину, закрывающая первый экран
    (Unsplash, 2200×640, показывается высотой 240 px). Первый экран был
    единственным местом без картинки — самое важное место страницы и самое
    сухое. Полоса намеренно низкая и без сюжета: её работа — дать вдох
    перед плотной сеткой запросов, а не рассказать что-то новое;
  - `img/about.jpg` — портрет в блоке «Обо мне» (Unsplash, кроп 5:6);
  - `img/room.jpg` — два кресла в блоке «Как проходит» (Unsplash, 1520×800);
  - `img/guide-cover.jpg` — **не фото, а настоящий рендер** первой полосы
    лид-магнита (`leadmagnets/out/psy/p-01.png`). Нарисованная обложка
    показывала то, чего нет; теперь в тёмной полосе лежит тот самый PDF,
    который человек получит на почту.
- **Рисунки удалены.** До фотографий сцены рисовались кодом: `art_export.py`
  импортировал `leadmagnets/art.py` из соседнего проекта. Эта связь мешала
  вынести лендинг в отдельный репозиторий, а после перехода на фото стала
  ненужной — удалены и папка `art/`, и скрипт. Прошлая версия осталась
  в истории приватного репозитория `yamizxcq/valora`, коммит `184adff`.
- **Лицо со стока ≠ Анна Ремизова.** На демо это оговорено в подвале,
  но при сдаче живому заказчику портрет заменяется на его собственный.
- **Блок «с чем я не работаю»** — единственное, чего нет в образце.
  На сайте психолога честный отказ работает сильнее ещё одного преимущества.
- **Отзывы анонимные**, с пометкой о письменном согласии: именные отзывы
  в психологии — нарушение конфиденциальности, и клиент это считывает.
- **Формы ничего не отправляют** — показывают заглушку об успехе. Образец
  устроен так же: «как бы рабочий сайт».

## Грабли

- **`img` с атрибутами `width`/`height` нужен `height: auto`.** Без него
  ужатая по ширине обложка гида сохраняет исходную высоту и получает
  тёмные поля сверху и снизу.
- **Инлайновый `style="max-width:760px"` перебивает `img { max-width: 100% }`**
  и ломает страницу по горизонтали на телефоне. Только класс.
- **`.magnet__form` наследует `flex-direction: column` от `.form`.**
  Пока не задашь `row`, `flex: 1 1 220px` уходит в высоту и поле почты
  вытягивается на 220 px вниз.
- **Edge не рисует окно уже ~500 px.** Просишь 420 — получаешь вьюпорт 476
  и снимок, обрезанный справа; вёрстка кажется битой, хотя `scrollWidth`
  равен `clientWidth`. `shot.py` поднимает ширину до 500 и говорит об этом.
## Что заменить под живого заказчика

`index.html`, по разделам: имя и вордмарк, цифры в ленте под первым экраном,
таблица фактов в «Обо мне», цены, отзывы, контакты (телефон, telegram, почта,
адрес) и пометка о демо в подвале. Палитра — шесть переменных в начале
`styles.css`. Фотографии — три файла в `img/`, обязательно вместе с портретом:
лицо со стока под именем реального специалиста на работающем сайте недопустимо.

Формы сейчас показывают заглушку и никуда не отправляют — как в образце,
по которому собирался лендинг. Для живого заказчика это первое, что
придётся доделать: GitHub Pages статический, обработчик заявки живёт снаружи.

## Откуда лендинг

Собран в Valora как третий деливерабл после презентации КП и лид-магнитов.
Исходники бренда, КП и гида — в приватном `yamizxcq/valora`; этот репозиторий
публичный, потому что раздаётся с GitHub Pages. Гид «7 ошибок», на который
ведёт сайт, лежит там же в `leadmagnets/`.
